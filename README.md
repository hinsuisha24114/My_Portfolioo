# Isha Hinsu — Portfolio Landing Page

Dark, moody cinematic portfolio built with React + Vite + TypeScript + Tailwind CSS + Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Design System

- Fonts: Almarai (body) + Instrument Serif (italic accents)
- Colors: Black backgrounds, warm cream (#DEDBC8 / #E1E0CC)
- Animations: WordsPullUp, scroll-linked text reveal, staggered card entrances
- Sections: Hero (video + giant name), About, Projects/Skills/Contact

Content adapted from Isha Hinsu's professional profile while preserving the original Prisma creative-studio layout and interactions.
